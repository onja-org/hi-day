# Workforce Monitoring Platform

This is a pnpm workspace monorepo with two packages: `frontend` (Next.js) and `backend` (NestJS). Each has its own conventions doc — read the one that matches what you're working on before making changes:

- **Frontend work** (anything under `frontend/`): read [`frontend/CLAUDE.md`](frontend/CLAUDE.md).
- **Backend work** (anything under `backend/`): read [`backend/CLAUDE.md`](backend/CLAUDE.md).

See [`CONTEXT.md`](CONTEXT.md) for domain terms (Organisation, Membership, etc.) shared across both packages.
